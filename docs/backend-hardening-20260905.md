# 后端缺陷修复与策略确认（2026-09-05）

本轮依据“后端技术缺陷与策略疑惑”讨论及确认实施；API 契约为 `5.18.0-dev.20260905.1`。

## 已确认策略

- 创作 Thread 草稿按创建时间超过七天硬删除，编辑不延长；独立云草稿不变。
- 媒体暂不提供私密保护，已知图片 URL 仍公开。回收使用数据库领取标记与引用约束避免误删，完成态孤儿回收默认关闭。
- 经验暂不扣回；既有日限额和幂等账本继续生效。
- 推荐鼓励真实玩家数、参与人天、楼主回复和有效文字，公式与去重口径见 [主题模块](modules/threads.md)。缓存每十分钟原子重建，丢失后恢复，恢复失败明确 503。
- 主贴和子贴正文可搜索，旧客户端省略 `includeBody` 仍只搜 FLOOR；Web 开启 BODY 并提供正文定位。
- 拉黑禁止双方新互动并互相隐藏；历史数据库记录保留，第三方可见，双方都解除后恢复。自己的撤回、取消关系及删除走原正式生命周期。
- `CLOSED` 表示“已停招”，`FINISHED` 表示“已完结”；发言权限仍由 PostingPolicy 决定。
- 私聊不增加新功能；仅随统一拉黑策略隐藏会话和未读数，待处理首条消息也保留。

## 修复与验证入口

Outbox 监听失败向投递层传播，支持重试；Markdown 图片遮罩采用一致的 UTF-16 偏移，避免 emoji 附近校验绕过；推荐翻页额外探测一条。媒体绑定与回收共用数据库锁，失败保留领取标记供重试。导出限制 10000 条内容、16 MiB 正文、64 MiB 实际图片字节和单进程并发，超限分别 413/429，响应成功状态与契约统一为 200。

公网冒烟补充覆盖了先删除、后消费事件的时序：发帖监听器复用当前内容可见性，已删除或已不可访问的源内容直接结束，不再生成提及、通知或活动缓存；数据库查询故障仍进入重试。隔离 API 矩阵验证此类 Outbox 记录首次消费成功并保留审计历史。

双向可见性集中在 access 查询条件；有身份的详情不复用匿名共享缓存。分页、计数、嵌套引用、成员、通知、私聊与导出均使用当前查看者范围。拉黑与新互动共用有序用户行锁；数据库事务中的最终检查防止先读后写竞态。

- `pnpm check:full`：单元、契约、构建、认证、经济、真实 API、媒体回收和推荐集成。
- `scripts/block-search.e2e.ts`：隔离数据库三账号，匿名缓存预热、双向/第三方可见性、正文搜索、嵌套回复、通知、导出、私聊历史、解除恢复及并发拉黑/关注。
- `pnpm test:search:benchmark`：仅允许 loopback，独立数据库自动建表、填充、测试后删除；原始 EXPLAIN 见 [基准证据](evidence/search-benchmark-20260905.json)。

## 十万条搜索基准

在共享 VPS 的隔离 PostgreSQL 上，1000 个主题、100000 条长度有差异的正文，平均 674 字节（146–1202），混合 BODY/FLOOR、私密/删除内容和拉黑作者。查询实际 SearchService，显式开启 BODY，有身份过滤，每组五次；包含数据库查询、投影与往返，非生产 SLA。

| 查询 | 中位毫秒 | 最慢毫秒 |
| --- | ---: | ---: |
| 常见二字／全站 | 1741 | 2005 |
| 常见三字／全站 | 1297 | 1510 |
| 稀有二字／全站 | 963 | 1051 |
| 稀有三字／全站 | 16 | 21 |
| 常见二字／帖内 | 28 | 34 |

两字匹配可能扫描较多行，当前保留 pg_trgm 与 SQL 两秒超时；超时返回可重试 503。更长或低频关键词明显受益于索引。后续真实规模超过此基准、超时率持续升高时，再决定中文全文索引方案。
