# API 速查：草稿（Drafts）

> 全局 5 槽位草稿池。与主题帖沙盒草稿是两个概念。

## 端点总览

| Method | Path | 认证 | 用途 |
|--------|------|------|------|
| GET | `/drafts` | AuthRead | 全部草稿 |
| GET | `/drafts/slots` | AuthRead | 槽位使用情况 |
| POST | `/drafts` | Auth | 保存草稿 |
| GET | `/drafts/:id` | AuthRead | 单条草稿 |
| PATCH | `/drafts/:id` | Auth | 更新草稿 |
| DELETE | `/drafts/:id` | Auth | 删除草稿 |

---

## 核心规则

- 每个用户最多 5 条草稿，按 `slot` 1-5 编号。
- 草稿**不与子贴/主题帖绑定**，是纯文本缓存。
- 指定 slot 时若已存在则覆盖，不存在则新建。
- 不指定 slot 时自动找第一个空闲位。
- 5 槽全满时返回 `400` "草稿位已满（5/5），请先删除旧草稿"。

---

## GET /drafts/slots

获取槽位使用情况。

### 响应

```json
{
  "code": 0,
  "data": {
    "usedSlots": 3,
    "maxSlots": 5,
    "slots": [1, 2, 5]
  }
}
```

---

## POST /drafts

保存草稿。

### 请求

```json
{
  "slot": 1,
  "content": "临时保存的回复内容..."
}
```

### 字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| slot | number | 否 | 1-5，不指定自动分配 |
| content | string | 是 | 草稿内容 |

### 响应

返回创建或更新后的 Draft 对象。

---

## 与主题帖沙盒草稿的区别

| 维度 | 主题帖沙盒草稿 | 全局草稿池 |
|------|---------------|-----------|
| 接口 | `POST /threads` | `POST /drafts` |
| 数据库表 | `Thread` | `Draft` |
| 数量限制 | 无明确限制 | 最多 5 条 |
| 是否绑定子贴 | 是 | 否 |
| 是否可发布 | 是 | 否 |
| 用途 | 主题帖创作全流程 | 临时缓存某段文本 |

---

## 前端使用建议

1. **不要把主题帖创建流程的自动保存存到全局草稿池**。
2. 全局草稿池适合：
   - 用户在回复编辑器中临时切走。
   - 用户主动点击"保存到草稿"。
3. 展示草稿列表时，可以显示前 50 字作为摘要。
