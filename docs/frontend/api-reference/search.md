# API 速查：搜索（Search）

> 基于 PostgreSQL ILIKE 的全文搜索，同时搜索主题帖标题和帖子内容。

## 端点

| Method | Path | 认证 | 用途 |
|--------|------|------|------|
| GET | `/search?q=` | Public | 全文搜索 |

---

## GET /search

```http
GET /api/v1/search?q=关键词
```

### Query 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| q | string | 是 | 搜索关键词 |

### 响应

```json
{
  "code": 0,
  "data": {
    "threads": [
      {
        "id": "t1",
        "title": "包含关键词的主题帖",
        "category": "RPG",
        "owner": { ... },
        "createdAt": "..."
      }
    ],
    "posts": [
      {
        "id": "p1",
        "content": "包含关键词的帖子内容",
        "floorNumber": 5,
        "threadId": "t1",
        "subthreadId": "s1",
        "author": { ... },
        "createdAt": "..."
      }
    ]
  }
}
```

### 规则

- 同时搜索主题帖标题和帖子正文。
- 主题帖结果仅包含 `published=true` 且 `visibility=PUBLIC` 的帖子。
- 帖子结果仅包含 `deletedAt: null` 的帖子。
- 两类结果各最多返回 50 条。
- 主题帖按 `updatedAt` 降序，帖子按 `createdAt` 降序。
- 空关键词返回 `{ threads: [], posts: [] }`。

---

## 前端实现建议

### 搜索页

- 顶部搜索框，支持回车触发。
- 结果分两个 tab 展示："主题帖"和"楼层"。
- 点击主题帖标题进入主题帖详情。
- 点击楼层内容进入对应主题帖并滚动到对应楼层。

### 搜索建议

当前后端没有搜索建议接口，前端可以直接在输入完成后触发搜索。

### 空状态

- 无关键词时显示"请输入关键词"。
- 无结果时显示"未找到相关内容"。

| 场景 | 错误 | 前端提示 |
|------|------|---------|
