# 主题底栏互动总数

## 主题互动人数（5.40）

`GET /threads/:id` 增加顶层 `bookmarkCount`、`subscriberCount`，均为非负整数。新后端在每个成功详情响应返回真实值，包括 `0`；OpenAPI 暂为可选，支持新客户端读取尚未升级的旧后端。缺失表示未知／未支持，客户端不得转成 `0`。

- `bookmarkCount`：未注销账号的实际主题收藏关系数，跨收藏夹按账号唯一；不受收藏公开开关影响，不返回收藏者或收藏夹身份。
- `subscriberCount`：未注销账号显式 `THREAD` 且 `targetUserId=null` 的官方更新订阅人数；不计特定玩家 `USER` 订阅，不因楼主／协作者自动收到通知而加人。仍存在的有效显式关系按关系计数，不因后来角色变化额外剔除。
- 总数不按查看者的拉黑关系改变；主题本身仍先执行既有可见性和双向拉黑校验，匿名／私密／草稿／软删除拒绝规则不变。仅公开已授权主题的汇总数，不新增用户列表。
- 两个数在同一数据库查询快照读取，不写入或信任匿名详情的 30 秒正文缓存。收藏、取消、移动收藏夹、订阅和取消的现有写接口不变；客户端在写入成功后重新读取详情获得权威总数，失败保留原状态，不把个人状态当成总数。
- 新增 `user_bookmarks_thread_idx`、`subscriptions_thread_type_target_idx` 两个索引支撑实时聚合；无计数字段回填、历史关系变更或正文迁移。

消费者依赖已提交 OpenAPI 同步生成；先兼容后端、再消费者，后端与 Web 兼容提交须先存在远端再批准切换。本变更不修改 Markdown、剪贴板或 Foundation 的视觉／编辑器协议，不提升 Foundation Tag，不清理任何旧字段或兼容路径。
