## 环境阻塞与待补验

原始 `pnpm check` 与 `pnpm check:full` 均实际运行。其 OpenAPI 子命令使用共享固定路径 `/tmp/wenyousite-openapi-check.json`，该文件不可由开发身份写入，返回 EACCES，导出进程随后未退出；仅终止本任务导出进程。未删除他人文件，改为任务独立路径导出并执行原有三项 OpenAPI 校验，其余门禁逐项等价运行。原始完整命令不能标为通过。

auth/economy E2E 因工作区缺 `.env` 失败；隔离 API E2E 缺 `DATABASE_URL`，media/ranking 集成检查同样缺数据库地址。没有读取受限的生产/迁移凭据、使用公网批量写入或另建基础设施。

具备授权的 loopback 可恢复测试数据环境后，须补跑 `pnpm check:full`；新增 HTTP 回归必须实际通过以下场景后才能完成后端验收：

- 游客不能管理；普通参与者及玩家不能修改权限；楼主与协作者可以保存。
- 三种权限下游客、楼主、协作者、玩家、普通参与者、登录非成员的详情能力，与楼层和楼中楼实际写入一致；公开帖登录非成员仅在开放策略首次发言后自动进入候选池。
- 标题、正文和权限联合保存，默认子贴版本只递增一次；其他子贴不变化。
- 旧客户端省略权限保留原值；非法值拒绝；默认子贴/正文版本冲突全部回滚。
- 后续停用标签校验失败，已执行的权限与正文修改真实回滚；并发同版本请求仅一个成功。

真实数据库事务、HTTP 权限矩阵与端到端检查尚未通过，不以模拟服务单元测试代替。PR 应保持 Draft，等待环境补验和负责人验收。

## 客户端与发布顺序

先合并并明确批准发布兼容后端，再发布消费者；新客户端不能依赖旧部署后端接受新增请求字段。Web / Mobile 基于已提交 OpenAPI 与 Foundation 接入已有设置页统一保存，完整页面 UI 验收由各端提供，不能用后端检查代替。创建流程、其他子贴策略及现有接口均保留。
