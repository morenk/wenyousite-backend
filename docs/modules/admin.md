# 管理后台

## 概述
管理后台模块提供最简入口端点，返回服务运行状态信息。管理后台的前端面板和更多 API 待后续开发。

## 涉及的模型

（无专属模型，复用现有模型）

## API 端点

| 方法 | 路径 | 认证 | 说明 |
|------|------|------|------|
| `GET` | `/admin` | 无 | 管理后台入口，返回服务名、状态、文档地址 |

## 核心业务规则

- 返回固定 JSON：`{ name: '温油站管理后台', status: 'running', docs: '/api/docs' }`

## 设计决策

- 管理后台当前仅作为占位入口，不承载实际管理功能
- 后续管理操作（用户管理、帖子审核、举报处理）将逐步从各业务模块迁移至此
