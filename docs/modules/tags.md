# 标签

## 概述

标签模块管理平台级主题帖标签（TopicTag），用于跨帖搜索与筛选。标签名称空间允许已验证用户随主题帖创建扩展，展示属性与启停状态由管理员治理；子贴不再提供标签能力。

## 涉及的模型

| 模型             | 说明                                     |
| ---------------- | ---------------------------------------- |
| `TopicTag`       | 平台级标签，全局唯一名称，用于主题帖筛选 |
| `ThreadTopicTag` | 主题帖与 TopicTag 的多对多关联表         |

## API 端点

| 方法    | 路径                 | 认证              | 说明                                 |
| ------- | -------------------- | ----------------- | ------------------------------------ |
| `GET`   | `/tags`              | `@Public()`       | 搜索 TopicTag（可选 `?q=` 模糊搜索） |
| `GET`   | `/tags/:id`          | `@Public()`       | 获取单个标签详情                     |
| `POST`  | `/tags`              | `@Auth()`         | 创建 TopicTag（兼容发帖端自由标签）  |
| `GET`   | `/admin/tags`        | `@AdminAuth()`    | 管理员列表（含停用项）               |
| `POST`  | `/admin/tags`        | `@AdminAuth()`    | 管理员新增带描述、颜色和排序的标签   |
| `PATCH` | `/admin/tags/:id`    | `@AdminAuth()`    | 编辑、排序或停用标签                 |
| `GET`   | `/threads?tagId=:id` | `@OptionalAuth()` | 精确列出关联该标签的公开已发布主题帖 |

## 核心业务规则

- TopicTag 的 `name` 会先裁剪首尾空白并全局唯一；并发创建最终由数据库唯一键裁决，冲突统一返回 409
- TopicTag 可配置 `color`、`description`、`sortOrder` 和 `isActive`；公开列表只返回启用项并按管理员顺序排列
- 标签名限制 1-20 字符，仅允许字母、数字、下划线、中文和 `#`
- 单个主题帖最多 5 个标签；服务层会再次裁剪、去重和校验，不能依赖 DTO 作为唯一防线
- `POST /tags` 与主题帖编辑器均可创建缺失名称；管理员接口负责标签描述、颜色、排序和停用，不把现有 Web/Flutter 自由标签流程改成管理员审批
- `findOrCreate` 方法批量查找或创建标签，用于创建/编辑主题帖时关联标签；已停用同名标签不能被重新创建或关联。创建草稿时该操作与 Thread/OWNER/默认子贴在同一事务中，事务失败不会留下孤儿标签
- 标签帖子列表使用稳定的 TopicTag ID 查询；不存在的 ID 返回空列表，标签详情仍由 `GET /tags/:id` 返回 404

## 设计决策

- `findOrCreate` 采用先查询已有、再批量创建缺失的模式，减少数据库往返次数；返回顺序与规范化后的输入一致
- TopicTag 创建通过 `createMany(skipDuplicates)` 批量写入缺失标签，避免逐条创建的 N+1 问题并容忍并发抢建
- 事务客户端调用不提前失效公共缓存；由提交后的主题帖流程统一触发失效，避免回滚事务污染缓存时序
