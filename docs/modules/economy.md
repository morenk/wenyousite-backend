# 等级与温油模块

## 业务边界

等级用于展示文字创作社区内的持续参与度，温油用于读者激励创作者。两套数值相互独立：经验不可消费，温油不可购买、提现或兑换现实资产；所有温油金额都是整数升。

## 等级与经验

等级最高 Lv.9，门槛依次为 `0 / 50 / 200 / 600 / 1500 / 3500 / 7000 / 14000 / 30000`。Lv.9 后经验继续累计。等级在用户摘要、内容作者和公开主页显示；精确经验、当前级起点和下一级门槛仅通过本人资料返回。

经验按北京时间自然日分项限制：日活保底 +2（每天 1 次，可由签到或首次有效行为领取）；发布公开主题帖 +30（1 次），创建私帖在首个其他成员有效回复后 +15（与公开主题帖共用 1 次主题帖名额），楼层或楼中楼回复作者 +3（5 次），楼主按不同回复用户 +2（5 次）；发布动态 +4（3 次），动态评论或回复作者 +2（5 次），动态作者按不同评论用户 +1（5 次）；主题帖首次获得不同用户点赞 +2（10 次）；投喂给不同收款人 +1（3 人），收到不同投喂者 +2（5 人）。正文不算回复，自赞、自评和自我投喂不计；取消后重新点赞不重复获得经验；打赏经验与金额无关，避免用温油刷经验。事件以业务来源幂等，日统计只维护计数，不扫描历史内容；预留的撤销流程会写负向事件并同步降级，不提供普通用户接口。

## 温油签到与打赏

登录客户端调用 `POST /wallet/check-in` 自动签到。同一用户同一北京时间日期只会领取一次随机 1～3 升温油；日活经验可以已经被当天首次有效行为领取，届时签到仍成功但 `experienceAwarded=0`，重复调用返回当天结果且 `claimedNow=false`。

用户可以向已发布且有权访问的主题帖楼主，或直接向有效用户打赏不少于 2 升。禁止自我打赏和双向任一方存在拉黑关系；余额不足不会产生部分交易。收款人入账 `floor(总额 × 85%)`，其余进入唯一平台钱包。打赏最终有效，不随主题帖后续删除或权限变化退款。

每次打赏携带 UUID `clientRequestId`。同一付款钱包、相同 ID 和相同请求载荷重放返回原交易快照；同一 ID 用于不同请求返回 `IDEMPOTENCY_KEY_REUSED`。写入使用 Serializable 事务、钱包行锁和余额条件更新，账本、余额、公开统计及 Outbox 同事务提交。PostgreSQL CHECK 和延迟约束触发器校验类型形状、非负快照、钱包角色及签到交叉记录；账本触发器拒绝修改、删除或截断，历史目标只能软删除。

## 可见性与接口

- `GET /wallet`：本人余额和累计收款统计。
- `POST /wallet/check-in`：每日幂等签到。
- `GET /wallet/transactions`：本人私密流水，收款记录显示打赏者；公众无法查询捐赠人或交易明细。
- `POST /threads/:id/tips`、`POST /users/:id/tips`：每用户每分钟最多 5 次打赏请求。
- 主题帖列表/详情公开 `tipTotal`；用户主页公开 `receivedTipTotal` 和 `receivedTipCount`，均按付款总额统计。

打赏完成写入 `tip.completed` Outbox，异步生成站内通知与移动推送并刷新主题帖智能排序。智能排序活跃度为 `回复×2 + 点赞×3 + 浏览×0.3 + 5×ln(1+累计温油)`，再除以 `(存续小时+2)^1.25`；最新与置顶排序不受影响。
