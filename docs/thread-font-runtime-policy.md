# 字体运行策略 v2

独立只读入口 `GET /api/v1/meta/text-fonts/runtime-policy` 返回 [策略 JSON](../contracts/thread-font-runtime-policy-v2.json)，以 [schema](../contracts/thread-font-runtime-policy-v2.schema.json) 和[固定夹具](../contracts/thread-font-runtime-policy-v2-fixtures.json) 校验。HTTP 契约为 `5.42.0-dev.20261022.1`，字体正文 v1 与 manifest schema v1 保持兼容；目录 1.2.0 包含 28 款已核验分片字体（中文 12／日文 10／英文 6）。

## 发现、绑定与兼容

接口是 `@Public()`，不解析身份，成功返回标准 envelope，缓存 300 秒。旧消费者继续读取原 `/meta/text-fonts`，其响应形状不变；当前目录返回新的 manifest 描述符，旧不可变路径保留。`limits` 和旧小城 `additionalSessionBytes` 仍保持原累计语义。v2 是显式选择的独立运行策略，不把旧字段改成窗口额度。

新消费者依次校验目录描述符、manifest 字节／SHA／schema、策略 schema 与 `policyVersion=2`，并要求 `manifestSha256` 同时等于描述符和实际文件哈希。策略缺失、旧后端 404、未知版本／模式或绑定不符时，不启用 v2；仍可按已验证的 v1 限额读取，不能把失败当作无限额度。运行策略不开放字体新写，也不表示资产已发布：`assetBaseUrl=null` 时只显示系统回退，不下载字体或第三方上游。缓存版本错配可按正常元数据刷新重取，不能跨 manifest 拼装策略。

现有绑定 SHA 为 `e2836703a30eec5f59dd9d4d72f6887756c2dd30c070606db5cee258ebd0efa3`。生成器从完整已提交 manifest 计算绑定与注册账本，运行 API 不扫描仓库文件。未来更新必须重新生成、校验并发布策略；不能在现有哈希路径覆盖文件。

## 可续用的网络窗口

| 平台 | 滑动窗口 | 普通字节 | 请求数 | 并发 |
| --- | --- | --- | --- | --- |
| Web | 60 秒 | 16 MiB | 64 | 2 |
| Mobile | 60 秒 | 24 MiB | 64 | 1 |

窗口按单调时钟保存每次实际请求开始时的完整描述符字节预留；事件年龄达到 `windowMs` 才过期，不是墙钟整点清零。预留与并发准入原子执行。元数据、manifest、许可、归属、字体、失败、取消及重试均计请求；网络缓存重验证也计请求，纯本地已核验缓存命中不计网络窗口。元数据无字体资产描述符时，消费者需在发出请求前按本地固定 64 KiB 响应上限预占，并执行流式长度上限，不能按响应自报大小放宽。

失败不立即退还已开始请求的网络预留，但额度随时间自然恢复。请求或字节不足时将可见需求排队，在最早预留过期后自动重新调度，不永久记为失败。离线暂停发出请求，网络恢复／返回前台唤醒仍可见的需求；重新评估窗口、退避和 Retry-After，不新增 UI、不要求刷新或重启。已不可见需求退出队列，不能积累所有历史浏览任务。

当前 v2 只绑定全分片目录，不包含 `originalAsset`、`network.originalWindowBytes` 或 `web.residency.originalSfntBytes`，也不接受原件例外。小城已从当前可选目录和发布对象集合移除；历史 ID 仍可解析、保留或去除，但不能新增／扩展范围。客户端遇到历史小城内容保留文字和标记，使用系统回退。源锁、原件描述和旧许可审计见[退役记录](../contracts/archive/thread-font-xiaocheng-lafeng-v1.json)。

## 传输超时与取消

Web 与 Mobile 的 `network` 均显式返回 `timeoutMode: "idle-with-total-cap"`、`timeoutMs: 15000`、`maxTransferMs: 600000`。这只修正尚未发布的 v2 原型；旧 v1 manifest 的 `downloadTimeoutMs: 15000` 继续表示总超时。两端必须同步本次完整策略形状和 API 版本；缺少新字段或不识别模式时，按发现规则回退旧策略，不能仅凭 `timeoutMs` 猜测新语义。

实际发出请求时，以单调时钟同时启动 idle 和总传输计时；排队、等待额度或退避不算传输时长。首响应等待包含在最初的 15 秒内，收到响应头不重置 idle；只有收到通过当次流式长度检查的非空正文数据块才将 idle 截止设为“当前时刻 + 15 秒”。空块、响应头、重渲染和网络窗口续额都不算字节进度。连续有进度且未超过单资产上限的分片可超过 15 秒完成；总截止始终为“实际请求开始 + 600,000 毫秒”，任何进度都不能延长它。

每次读取／完成回调都先核对两个截止；达到任一截止即取消底层请求及 reader，丢弃未核验部分，按既有暂时超时退避，不因定时器回调延迟接受迟到数据。恰好位于截止的数据块或 EOF 也已超时；两个截止相同时总时限优先。响应体结束后清除计时器，后续完整长度、SHA、MIME 和解码验证继续执行。请求进行中即使网络窗口已续额，也继续占用原并发槽；同 SHA 合并继续生效，不能另开同一资产下载。

共享需求全部离屏或应用进入后台时，取消当前传输并释放待下载引用；仍有可见 lease 时不因单个组件离屏中断共享请求。此类需求取消不增加网络失败计数，重新可见／前台恢复后仍须满足已有窗口、退避和 Retry-After；撤回／不可用则维持安全隔离，不自动重排。已开始的请求预算不立即退款，取消确认后才释放并发槽，不放宽原生注册或驻留约束。

此计时同时适用于字体、manifest、许可／归属和元数据。元数据仍执行 64 KiB 本地流式上限；有描述符的资源仍按固定长度、哈希及对应单资产上限校验，不能靠持续小块逃避长度限制。HTTP 状态在首响应时按原分类处理，错误正文进度不能延缓拒绝或把永久错误改为可重试；304 仍只允许复用已验证缓存。正文未读完就断开仍是暂时网络失败，长度／SHA／MIME／解码错误仍不进入无限重试。

## Web 可回收活动集合

同一 `Document.fonts` 注册域共用一个运行时，多个阅读组件、路由与阅读窗口不得各建独立账本。仅主题正文可见文字持有 lease；列表、搜索、消息、通知、分享摘要不请求字体。活动家族上界为当前全部 28 款；face 上界 64。SFNT 输入估算上界 16 MiB，不再提供原件额外驻留槽。不同浏览器文档是独立注册域，本契约不声称限制整个浏览器的 RSS。

`maxSfntBytes` 不使用 WOFF2 压缩下载长度。下载前按已校验 manifest 的 `shard.mobile.bytes` 预占；WOFF2 通过完整 SHA、长度与 MIME 验证后读取头部 `totalSfntSize`，解码／注册前按两者较大值补足预留。两值可能因转换与表布局不同而不相等，不能要求逐字节长度相等，也不能忽略较大值。预留包含正在解码／注册的片，避免并发越界。[WOFF2 规范](https://www.w3.org/TR/WOFF2/#woff20Header) 将头部总长度定义为参考值；本字段是解压后 SFNT 输入的参考估算账本，不保证重建后的精确长度，也不是字体引擎、字形缓存、临时复制或浏览器峰值内存上限；消费者另行验证实际 native／RSS 峰值。

离屏释放引用后可 LRU 淘汰无引用 face，解除字体注册并清除相应二进制、已完成 Promise、family 列表及保护集合中的引用；实际释放后才归还驻留额度。网络窗口恢复不能清零驻留账本。瞬时空间不足先保持系统回退，待 lease 释放或资源可用后自动加载；不会因为历史已经见过 8 个家族而永久停止。

按资产 SHA 合并并发与驻留引用。网络失败且没有原生注册时释放下载／待注册引用；校验／解码失败进入该资产的隔离状态，不能通过重建 FontFace 绕过隔离或活动集合上限。

## Mobile 有限注册快照

Mobile 使用 `fixed-manifest`，不继承 Web 的卸载假设，也没有累计 8 家族／32 face 截断。每个 FlutterEngine 首次接受策略时，固定该已核验 manifest 的可注册全集；目录变化不向当前引擎无限追加新资产或新别名。已有快照内的资产可继续按可见字符渐进获取，不预下载全集。新的未验证快照不扩展当前注册集合，也不要求用户为继续浏览当前快照重启。

当前快照为 868 个唯一 Mobile 资产、184,645,488 字节；按 `(asset SHA, family)` 去重也是 868 个注册键及相同输入字节。生成器和消费者均重新汇总：重复同键只计一次，同 SHA 多 family 则每个原生注册分别计注册数量和输入字节，避免别名绕过。源码固定接受边界为 1,024 个资产／注册键与 256 MiB 文件输入，两套汇总均不得超过；这是本地安全接受边界，远端即使扩大字段也不能授权扩大客户端边界。

这些数字不是 RSS／native 内存上限，也不代表低端 Android 安全。完整目录输入 176.09 MiB、常用 28 个 core 输入 35,570,596 字节，仅用于描述固定资源集合；真实设备原生内存、解码峰值和多轮浏览由 Mobile 另行验收。

原生注册前原子登记 `(SHA, family)`，每键最多调用一次，所有阅读窗口共用账本。成功保留注册记录；失败单独隔离并保留占用，按可能已经分配原生资源处理，不用再次调用同键尝试抵消未知副作用。下载／网络失败尚未调用原生时不消耗注册次数，可受网络窗口和退避控制重试。快照中的注册键不随时间窗口新增注册额度。完成后不长期保留 Dart 字节／已完成 Future；磁盘仍使用 64 MiB LRU，磁盘淘汰不代表原生字体卸载，也不允许同键重复原生注册。

## 资源级恢复

按资产 SHA 合并网络请求并维护连续暂时失败计数。第 n 次失败使用 `delayCeilingsMs[min(n,7)-1]`：1、2、4、8、16、32、60 秒，后续保持 60 秒上限。full jitter 定义为 `floor(U × (ceiling + 1))`，`0 <= U < 1`，得到整数毫秒；成功后清零失败计数。下一次尝试时间取抖动退避、窗口可用时间与有效 Retry-After 的最晚值；Retry-After 支持非负秒数与 HTTP 日期，不能被 60 秒退避上限截短。日期按响应到达时的墙钟换算非负等待时长，再转换成单调时钟截止时间；过期日期不增加等待，非法值忽略。已知离线时不消耗一次失败计数或请求额度。

仅网络错误、超时和 HTTP 408／429／500／502／503／504 属于暂时失败。schema、身份、SHA、长度、MIME、解码错误以及撤回／不可用状态不进入无限暂时重试；当前资产保持回退／隔离，只有新的已验证描述符或明确资源修复流程才能重评估。Mobile 已发起原生调用的键仍遵守引擎期单次约束。在线事件、重渲染与窗口续额均不能清除这些安全隔离状态。

网络窗口与驻留是两本独立账。通用 6 MiB 单资产、64 MiB 持久缓存、自有来源与完整性校验继续执行；现有发布存储与月流出硬上限仍需运营网关执行，客户端续额不等于解除服务端流量约束。

## 生成与验证

`pnpm text-font:policy:generate` 从已提交 manifest 生成策略 JSON 与 TypeScript 索引；`pnpm text-font:check` 校验严格 schema、原 manifest 未改义、源码生成一致性、快照去重／别名、越界拒绝、窗口边界、退避及传输轨迹夹具；传输轨迹覆盖持续 100 秒完成合法分片、首响应／idle 边界、空块、10 分钟总限、排队、取消及元数据长度拒绝。公开接口及 invalid bearer 不解析身份由隔离字体 E2E 覆盖。该任务不改字体二进制，不改正文／剪贴板协议，不迁移数据库、不发布资源或部署。

`transferCases` 是客户端共用的确定性传输阶段轨迹：时间均为同一单调时钟的毫秒，`repeat`／`everyMs` 展开等间隔事件；`queuedAtMs` 不进入传输计时，`startedAtMs` 才是起点。`expected.acceptedBytes` 只计未超过流式上限的已接受块，`complete` 不代替完整性校验或字体注册成功。后端检查器核对这些轨迹与策略数值，两端仍须以实际流式读取实现消费夹具并验收慢链路。
