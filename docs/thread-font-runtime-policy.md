# 字体运行策略 v2

独立只读入口 `GET /api/v1/meta/text-fonts/runtime-policy` 返回 [策略 JSON](../contracts/thread-font-runtime-policy-v2.json)，以 [schema](../contracts/thread-font-runtime-policy-v2.schema.json) 和[固定夹具](../contracts/thread-font-runtime-policy-v2-fixtures.json) 校验。HTTP 契约为 `5.42.0-dev.20261021.1`，字体正文 v1、目录 1.1.1、manifest schema v1、29 款资源与许可均不变。

## 发现、绑定与兼容

接口是 `@Public()`，不解析身份，成功返回标准 envelope，缓存 300 秒。旧消费者继续读取原 `/meta/text-fonts`，其响应形状和 manifest 字节完全不变；旧 `limits` 与小城 `additionalSessionBytes` 仍是原累计语义。v2 是显式选择的独立运行策略，不把旧字段改成窗口额度。

新消费者依次校验目录描述符、manifest 字节／SHA／schema、策略 schema 与 `policyVersion=2`，并要求 `manifestSha256` 同时等于描述符和实际文件哈希。策略缺失、旧后端 404、未知版本／模式或绑定不符时，不启用 v2；仍可按已验证的 v1 限额读取，不能把失败当作无限额度。运行策略不开放字体新写，也不表示资产已发布：`assetBaseUrl=null` 时只显示系统回退，不下载字体或第三方上游。缓存版本错配可按正常元数据刷新重取，不能跨 manifest 拼装策略。

现有绑定 SHA 为 `7aab91a436933049bc8f55c1aba6085078a251d174c5b253456d3af0c91a0582`。生成器从完整已提交 manifest 计算绑定与注册账本，运行 API 不扫描仓库文件。未来更新必须重新生成、校验并发布策略；不能在现有哈希路径覆盖文件。

## 可续用的网络窗口

| 平台 | 滑动窗口 | 普通字节 | 请求数 | 并发 | 原件独立网络额度 |
| --- | --- | --- | --- | --- | --- |
| Web | 60 秒 | 16 MiB | 64 | 2 | 固定 18,410,600 字节 |
| Mobile | 60 秒 | 24 MiB | 64 | 1 | 0；原件计入普通 24 MiB |

窗口按单调时钟保存每次实际请求开始时的完整描述符字节预留；事件年龄达到 `windowMs` 才过期，不是墙钟整点清零。预留与并发准入原子执行。元数据、manifest、许可、归属、字体、失败、取消及重试均计请求；网络缓存重验证也计请求，纯本地已核验缓存命中不计网络窗口。元数据无字体资产描述符时，消费者需在发出请求前按本地固定 64 KiB 响应上限预占，并执行流式长度上限，不能按响应自报大小放宽。

失败不立即退还已开始请求的网络预留，但额度随时间自然恢复；超时仍为 15 秒。请求或字节不足时将可见需求排队，在最早预留过期后自动重新调度，不永久记为失败。离线暂停发出请求，网络恢复／返回前台唤醒仍可见的需求；重新评估窗口、退避和 Retry-After，不新增 UI、不要求刷新或重启。已不可见需求退出队列，不能积累所有历史浏览任务。

Web 小城下载只扣独立原件字节槽，其他对象不能借用；所有请求仍共用 64 次和 2 并发。Mobile 小城每次实际下载扣普通 24 MiB，没有额外网络额度。完整原件 SHA、18,410,600 字节和唯一 family 必须与 manifest 及策略一致。下载失败在后续窗口可静默重试，不能沿用 v1 的终身失败预留使它永久锁死。

## Web 可回收活动集合

同一 `Document.fonts` 注册域共用一个运行时，多个阅读组件、路由与阅读窗口不得各建独立账本。仅主题正文可见文字持有 lease；列表、搜索、消息、通知、分享摘要不请求字体。活动家族上界为当前全部 29 款；face 上界 64。普通片 SFNT 输入估算上界 16 MiB，原件独占额外 18,410,600 字节；两种字节槽不能互借，原件仍占一个家族和一个 face。不同浏览器文档是独立注册域，本契约不声称限制整个浏览器的 RSS。

`maxSfntBytes` 不使用 WOFF2 压缩下载长度。下载前按已校验 manifest 的 `shard.mobile.bytes` 预占；WOFF2 通过完整 SHA、长度与 MIME 验证后读取头部 `totalSfntSize`，解码／注册前按两者较大值补足预留。两值可能因转换与表布局不同而不相等，不能要求逐字节长度相等，也不能忽略较大值。原 TTF 直接按固定文件长度计。预留包含正在解码／注册的片，避免并发越界。[WOFF2 规范](https://www.w3.org/TR/WOFF2/#woff20Header) 将头部总长度定义为参考值；本字段是解压后 SFNT 输入的参考估算账本，不保证重建后的精确长度，也不是字体引擎、字形缓存、临时复制或浏览器峰值内存上限；消费者另行验证实际 native／RSS 峰值。

离屏释放引用后可 LRU 淘汰无引用 face，解除字体注册并清除相应二进制、已完成 Promise、family 列表及保护集合中的引用；实际释放后才归还驻留额度。网络窗口恢复不能清零驻留账本。瞬时空间不足先保持系统回退，待 lease 释放或资源可用后自动加载；不会因为历史已经见过 8 个家族而永久停止。

原件按资产身份合并并发，正在加载与已驻留合计最多一份。网络失败且没有原生注册时，释放下载／待注册引用，不永久占用驻留槽；校验／解码失败进入该资产的隔离状态，不能以反复新建 FontFace 绕过原件单份约束。

## Mobile 有限注册快照

Mobile 使用 `fixed-manifest`，不继承 Web 的卸载假设，也没有累计 8 家族／32 face 截断。每个 FlutterEngine 首次接受策略时，固定该已核验 manifest 的可注册全集；目录变化不向当前引擎无限追加新资产或新别名。已有快照内的资产可继续按可见字符渐进获取，不预下载全集。新的未验证快照不扩展当前注册集合，也不要求用户为继续浏览当前快照重启。

当前快照为 869 个唯一 Mobile 资产、203,056,088 字节；按 `(asset SHA, family)` 去重也是 869 个注册键及相同输入字节。生成器和消费者均重新汇总：重复同键只计一次，同 SHA 多 family 则每个原生注册分别计注册数量和输入字节，避免别名绕过。源码固定接受边界为 1,024 个资产／注册键与 256 MiB 文件输入，两套汇总均不得超过；这是本地安全接受边界，远端即使扩大字段也不能授权扩大客户端边界。

这些数字不是 RSS／native 内存上限，也不代表低端 Android 安全。完整目录输入 193.65 MiB、常用 28 core 加小城输入 53,981,196 字节，仅用于描述固定资源集合；真实设备原生内存、解码峰值和多轮浏览由 Mobile 另行验收。

原生注册前原子登记 `(SHA, family)`，每键最多调用一次，所有阅读窗口共用账本。成功保留注册记录；失败单独隔离并保留占用，按可能已经分配原生资源处理，不用再次调用同键尝试抵消未知副作用。下载／网络失败尚未调用原生时不消耗注册次数，可受网络窗口和退避控制重试。原件已包含在 869 资产集合中，只计一次，不随时间窗口新增注册额度。完成后不长期保留 Dart 字节／已完成 Future；磁盘仍使用 64 MiB LRU，磁盘淘汰不代表原生字体卸载，也不允许同键重复原生注册。

## 资源级恢复

按资产 SHA 合并网络请求并维护连续暂时失败计数。第 n 次失败使用 `delayCeilingsMs[min(n,7)-1]`：1、2、4、8、16、32、60 秒，后续保持 60 秒上限。full jitter 定义为 `floor(U × (ceiling + 1))`，`0 <= U < 1`，得到整数毫秒；成功后清零失败计数。下一次尝试时间取抖动退避、窗口可用时间与有效 Retry-After 的最晚值；Retry-After 支持非负秒数与 HTTP 日期，不能被 60 秒退避上限截短。日期按响应到达时的墙钟换算非负等待时长，再转换成单调时钟截止时间；过期日期不增加等待，非法值忽略。已知离线时不消耗一次失败计数或请求额度。

仅网络错误、超时和 HTTP 408／429／500／502／503／504 属于暂时失败。schema、身份、SHA、长度、MIME、解码错误以及撤回／不可用状态不进入无限暂时重试；当前资产保持回退／隔离，只有新的已验证描述符或明确资源修复流程才能重评估。Mobile 已发起原生调用的键仍遵守引擎期单次约束。在线事件、重渲染与窗口续额均不能清除这些安全隔离状态。

网络窗口与驻留是两本独立账，原件身份例外也只作用于明确定义的槽。通用 6 MiB 单资产、15 秒超时、64 MiB 持久缓存、自有来源与完整性校验继续执行；现有发布存储与月流出硬上限仍需运营网关执行，客户端续额不等于解除服务端流量约束。

## 生成与验证

`pnpm text-font:policy:generate` 从已提交 manifest 生成策略 JSON 与 TypeScript 索引；`pnpm text-font:check` 校验严格 schema、原 manifest 未改义、源码生成一致性、快照去重／别名、越界拒绝、窗口边界和退避夹具。公开接口及 invalid bearer 不解析身份由隔离字体 E2E 覆盖。该任务不改字体二进制，不改正文／剪贴板协议，不迁移数据库、不发布资源或部署。
