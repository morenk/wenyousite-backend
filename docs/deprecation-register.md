# 富文本兼容保留登记

本页登记 Backend 富文本专项的兼容边界，治理级清理要求仍见[统一弃用规则](https://github.com/morenk/wenyousite-workspace/blob/main/AGENTS.md#清理门禁)。新增行为 fixture/schema 仅用于测试，不表示移除任何正文协议或已发布客户端。

| 保留项 | 处理边界 | 删除/收紧前必须具备的证据 |
| --- | --- | --- |
| Markdown v3/v4/v5 已支持正文 | 保留按实际能力读取；v5 编号不能证明引用空行或无损保护已接入 | 无消费者、数据已迁移、回归覆盖、回滚路径明确；独立 PR |
| 历史 LF、双 LF 与引用独占 `>` | 保留原段内/段落归属，不猜测按键来源，不批量改写 | 同上，不能以新编辑器输入规则覆盖历史语义 |
| clipboard v1 与 v2 | 合法 v1 恢复结构但不恢复对齐；合法 v2 严格重建；无有效载荷保持可见文本回退 | 接收能力和跨应用回退均有消费证据，不因平台名称跳过合法 envelope |
| 未知/不可无损转换原文 | 安全阅读与原文保留；不把降级结果当作可覆盖来源；只读且无新编辑时可保留原文快照后退出 | 明确读取、编辑、保存保护能力及失败回归；不能为通过 fixture 删除未知内容 |
| newline v1 revision 2、roundtrip v7 | 原 ID 和语义不变，新增测试契约继续引用 | 客户端已同步并验证对应独立语料后才能淘汰测试版本；不同时清理正文兼容 |

[能力与停止/回退验证](rich-text-stability-delivery.md)只提供离线证据和执行方案，不授权部署、停止线上写入口、回退进程或发布 APK；这些动作继续由负责人明确批准。
